# Archivo histórico

**Creado el 14 de noviembre de 2026** a pedido de Calvin: los informes muestran sólo lo vigente y aquí queda, con sus cifras y lo aprendido, cómo se trabajó antes, para no repetir errores.

## Cómo se organiza la documentación

1. **Documentación viva.** Dice sólo cómo es el producto hoy y cómo va a ser: `docs/plan/`, la arquitectura, los informes ejecutivos (el vigente es `docs/informes/2026-11-14-planos-de-carta-v4*`). Si algo cambia, se reescribe; no se acumulan «antes y después».
2. **Bitácora de decisiones.** Los ADR (`docs/mvp/adr/`) y el registro de cambios del plan (`docs/plan/04_Fases_y_Tareas.md` §11). Cada decisión lleva fecha, alternativas y quién la tomó. Ya existen; no se mueven.
3. **Archivo histórico (esta carpeta).** Cómo se hacía antes, cuánto costaba, cómo se midió y qué se aprendió. No se usa para decidir el presente; se lee antes de repetir una idea.

Un documento archivado apunta a las mediciones y a los ADR en vez de copiarlos. Si una cifra de aquí contradice un documento vivo, manda el documento vivo.
